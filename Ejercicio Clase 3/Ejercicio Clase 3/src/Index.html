Bienvenido RUTA RELATIVA

¿Qué son las rutas relativas?

Las rutas relativas indican la ubicación de un archivo en relación con el archivo actual. Por ejemplo: imagenes/foto.jpg o ../index.html.

Consejo

Usa siempre una estructura de carpetas ordenada para evitar errores en los enlaces.

  • css/ → estilos
  • js/ → scripts
  • imagenes/ → imágenes
